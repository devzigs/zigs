Prototype. All key material is made and used in your browser by the Rust code compiled to WebAssembly (FROST over RedPallas, ZIP 312, PCZT). Only public data and encrypted DKG messages go to the shared store. Your key share stays in this browser; use “Back up” to keep a copy.

This page works on Zcash testnet only. It reads blocks through a public lightwalletd proxy, which sees your IP address and the block ranges you ask for, but never a key. The page keeps its view of the wallet in memory and syncs again on every load. Do not send real funds to these addresses.
